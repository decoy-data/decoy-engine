## 2. Guarantee and non-goals

Rev 8.6 G1 to G6 carry unchanged. After the last slice here (S4b) merges:

- R1. `SCRATCH_NATIVE_PENDING` is empty. Every DuckDB connection call, Arrow or Parquet scratch read and footer read in an engine module runs through `scratch_native`, `scratch_native_iter` or an adapter, so a native failure leaves the boundary as a value-free error (rev 8.6 G6).
- R2. No internal out-of-core function takes a `Path` for scratch. `connect_duckdb`, the relation builders, the joiners, the stager, emit and `stream_table` take a `ScratchArena` (rev 8.6 I2). `ScratchArena._adopt` is gone.
- R3. Every engine-made scratch directory named in section 3 is an arena child, 0700 at creation under any umask, and every Python-written scratch file is 0600 (rev 8.6 G1).
- R4. Over the temp budget, or on a resource errno in a scratch write, the job stops, nothing commits, and the error carries a `QuotaReport` (rev 8.6 G3).

Non-goals: at-rest encryption (V2-LOG; criterion (d) records it); the sweep (row 74); byte quotas (row 58b); same-UID interference (rev 8.6 L6); Windows arenas before S1w (section 9.2).

Expected size: 16 slices (14 source slices plus M1 and M2 counted apart from M3), about 4,300 changed lines in total. New public names: none. New internal names: `read_footer` (ooc `_scratch.py`) and `ipc_iter_stream` (`fileaccess/adapters/arrow.py`), both named in rev 8.6.
