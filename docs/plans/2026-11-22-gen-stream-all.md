## 1. Frame

Evidence (audit, measured on the Dell 26-core node, 10M rows unless stated):

- The streamed lane generates a pooled `first_name` column to Parquet at 6.9M rows/s (1.46 s). Of the per-row cost, the pick is 48 ns: `values[idx].tolist()` 14 ns plus `pa.array(values)` 34 ns (`src/decoy_engine/generation/_faker_pool.py` `PooledSelector`, `src/decoy_engine/generation/_streamed.py:284` `_table_batches`). RNG indices plus `pyarrow.compute.take` cost 3.5 + 9 = 12.6 ns/row for the same output.
- Faker types outside the pool set run per row: email about 8.6k rows/s, phone about 65k rows/s. A 10M-row email column takes about 20 minutes.
- Pooling only starts at `N_THRESHOLD = 50_000` rows (`src/decoy_engine/generation/_faker_pool.py:236`). The comment above it records why: the pool is always built at `DEFAULT_POOL_SIZE` (10,000 Faker calls), so a 1k-row pooled column paid 10x its own cost.
- `provider` (npi about 80k rows/s), `lookup`, `statistical` and `inherit` are declined by `ADMISSION_MATRIX` (`src/decoy_engine/generation/_admission.py:46`). One declined column sends the whole plan to `_run_legacy` (`src/decoy_engine/generation/_streamed.py:543`) with free-text reason `legacy:<table.col:reason>` (`src/decoy_engine/generation/_streamed.py:597`).
- The run card does not show the generation route at all: `run_pipeline` calls `generate_tables` (`src/decoy_engine/execution/_pipeline_generate_mask.py:127`, `:138`), which returns tables only, so `GenerationResult.route` and `.declines` never reach `quality_metrics` or `CLI:src/decoy/cli/run/_render.py:177`. ROUTE-LABEL-TRUTH reads the mask lane's evidence, not `GenerationResult`.

Why the four kinds are streamable now (read at `70881ad79`):

- `provider` (`src/decoy_engine/generation/kinds/_provider.py`): its three draw paths are pool (`PoolBuilder` + `PoolSampler` REUSE), keyed (native per-row `generate(source_value=i)`) and batch (one Faker seeded once, then sequential calls). Each is a function of the row ordinal or of one sequential stream.
- `lookup` (`src/decoy_engine/generation/kinds/_lookup.py:271`): `random.Random(ctx.base_int("py")).choices(k=n)`. `choices` draws one `random()` per pick, so k calls of size b on one persistent `Random` equal one call of size n.
- `statistical` (`src/decoy_engine/generation/statistical/_sample.py:389`): `sample_column(spec, n, col_seed, parent_values, start=)` reseeds per row with `col_seed + start + i`; `generation/window.py` already reads windows through `start`.
- `inherit` (`src/decoy_engine/generation/relational/_inherit.py:65` `inherit_values`): a left join on the parent key through `lookup_parent_values` (`src/decoy_engine/generation/relational/_parent_lookup.py:60`). It needs the parent's key-to-value map, which the streamed lane can collect while it writes the parent.

## 2. Established solutions

- **Index then take.** Arrow's documented gather is `pyarrow.compute.take(values, indices)` (Arrow compute "Selections"); numpy `Generator.integers` gives the indices. This is the dictionary-decode pattern (Arrow `DictionaryArray`, Parquet dictionary pages).
- **Pool sampling for synthetic text.** SDV's `AnonymizedFaker` (RDT) builds a bounded set of Faker values and samples from it unless `cardinality_rule` is `unique`, and it never pools a column that SDV metadata marks as a primary key. Decoy already pools (`_faker_pool.py`, harness in `scripts/faker-determinism/`); this row widens the type set, adds the key opt-out SDV has, and drops the threshold.
- **Prefix-stable streams.** numpy `Generator` and Python `random.Random` are sequential: drawing b then c values equals drawing b+c. The existing streams (`src/decoy_engine/generation/_column_streams.py`) rely on this.
- **Bounded join for inherit.** A hash map built from the parent while it streams, then probed per child batch, is the build/probe hash join (Graefe 1993, "Query evaluation techniques"); its memory is reserved in the existing budget ledger.
- **Generated code from a data file.** The certified-pairs JSON is the source for locale-specific pairs only; a script writes that Python constant and a test fails when they differ (the same shape as the engine's other derived tables, for example `scripts/secret_material_census.py` and `tests/sentry/secret_material_census.json`). The separate global registry for the legacy ten is `POOL_ELIGIBLE_FAKER_TYPES` in `_faker_pool.py:62-75`; runtime eligibility and the harness `POSITIVE_CONTROL` both read that registry. Needed because `scripts/` is not in the wheel, so the runtime cannot read the JSON.

## 3. Guarantee and non-goals

After this row:

- A plan whose generate columns are all of the kinds `sequence`, `categorical`, `faker`, `reference`, `constant`, `distribution`, `windowed_date`, `provider`, `lookup`, `statistical` or `inherit` runs on the streamed lane, resident or with a sink, and never on `_run_legacy`.
- A pooled column's values come from one helper, `pool_take`, used by both `PooledSelector` and `PoolSampler`.
- Every `(type, locale)` pair in the certified file, and each of the 10 legacy types in every locale, pools at any row count with pool size `P = min(rows, 10_000)`, unless the column opts out. Opt-outs: `pooled: false`, `unique: true`, and (new) a key column: the target of a `reference` or `inherit` key in the plan. No clock-dependent type pools.
- Output is a function of (plan, seed) only: the same at any batch size, resident or sink, and on every rerun (A3, A7).
- A declined plan names each declined column with a code registered once in `reasons.route`; the run card shows the generation route and the first decline.

Non-goals: streaming `unique`, `derived`, `formula`, `grouped_series`, `derived_aggregate`, `group_key` (named exceptions); a native Rust Faker; the pool size knob; the mask path's Faker (NATIVE-THREADS-DEFAULT); CSV speed (CSV-WRITE-FAST).

## 7. Design notes

- Principles: single responsibility (the batch assembler moves out of `_streamed.py`, which keeps the run's orchestration; the change pain it removes is a 600-line file edited for every new kind). Open/closed for kinds (a new streamable kind registers a stream in `make_column_stream` and flips its admission row; no edit to the assembler).
- Pattern: Arrow dictionary decode (index then take); SDV pooled Faker with key opt-out; build/probe hash join.
- One place per fact: global legacy-ten eligibility (`_faker_pool.py` `POOL_ELIGIBLE_FAKER_TYPES`, read by runtime and harness); locale-pair eligibility (`certified_pairs.json`, generated module checked by a test); pool memory accounting (`_bounds.py` `faker_pool_resident_bytes`, used by preflight and the live ledger); clock types (`_reproducibility.py`); code summaries (`reasons.route` registry); pick (`pool_take`); key columns (computed once in `classify_plan`, passed as a typed frozenset).
- House style: `pool_opted_out` takes a typed `key_columns` argument, not a flag; no new flag arguments.

## 9. Acceptance tests (each fails before its slice, except A2, A3 and A5, controls that pass before and after)

S1a:

- **A2 take parity.** A legacy-10 type at 120,000 rows, with `null_probability: 0.1`, gives the same Parquet digest through `pool_take` and the moved assembler as at `70881ad79`; `PoolSampler` REUSE gives the same Series. A test asserts no other `pool.values[` gather remains under `src/decoy_engine/generation/`.
- **A3 batch invariance control.** Each pooled type, rows {1, 9,999, 10,000, 10,001, 120,000}, batches {1, 7, 4096, rows}: one digest per case across batch sizes and between resident and sink runs. This passes before and after S1a and S1b and guards their refactors.
- **A14 pool representation reservation.** With a bounded fake provider and 120,000 rows, the live ledger's recorded reservation equals `faker_pool_resident_bytes(10_000, payload)`, including the retained numpy/object and Arrow representations plus conversion peak. A budget of exactly that reservation plus the unchanged batch requirement admits and completes the job; one byte less refuses before the first provider call. Mutating the helper to omit either retained representation makes the recorded-reservation assertion fail.
